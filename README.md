# 2MONTHS — сайт ремонта квартир под ключ

Статический одностраничный сайт. Открывается напрямую (`index.html`) или через GitHub Pages.

## Структура
- `index.html` — вся разметка, стили и скрипты
- `images/` — сжатые изображения (JPEG)

## Публикация через GitHub Pages
1. Залейте содержимое этой папки в репозиторий (корень или ветку `gh-pages`)
2. В настройках репозитория → Pages → Source укажите нужную ветку/папку
3. Сайт будет доступен по адресу вида `https://<username>.github.io/<repo>/`
